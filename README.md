# 🏦 Sistema Bancário em Python

Sistema bancário simplificado desenvolvido via linha de comando (CLI) focado no aprendizado de Python, manipulação de arquivos JSON e controle de versão com Git e GitHub.

## Funcionalidades

- **Consulta de Saldo**: Exibe o saldo atual do titular da conta.
- **Saque**: Realiza retiradas verificando se há saldo suficiente.
- **Depósito**: Permite adicionar valores ao saldo atual.
- **Persistência de Dados**: Salva o estado da conta em um arquivo `banco.json` ao encerrar a aplicação.

## Tecnologias Utilizadas

- **Python 3**: Lógica de programação, funções e manipulação de arquivos.
- **JSON**: Formato para armazenamento dinâmico de dados.
- **Git & GitHub**: Versionamento de código e hospedagem do repositório.
